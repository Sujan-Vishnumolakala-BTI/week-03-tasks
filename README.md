# Week 03 Tasks

Welcome to the Week 03 Training Tasks repository.

## Important Note

The task files are available only in the **week-03/tasks** branch.

The **main** branch contains only the repository information.

To view the tasks, switch to the following branch:

```
week-03/tasks
```

## Folder Structure

```
week-03/tasks
│
├── Day-01
│   └── Day-01 tasks and solutions
│
└── Day-02
    └── Day-02 tasks and solutions
```

## Clone Repository

Clone the repository:

```bash
git clone https://github.com/Sujan-Vishnumolakala-BTI/week-03-tasks.git
```

Go into the repository:

```bash
cd week-03-tasks
```

## Switch to Task Branch

Checkout the task branch:

```bash
git checkout week-03/tasks
```

Now you can access the Week 03 tasks:

- Day-01
- Day-02

## Pull Latest Changes

To get the latest updates from the task branch:

```bash
git pull origin week-03/tasks
```

## Branch Information

| Branch | Description |
|--------|-------------|
| main | Repository information only |
| week-03/tasks | Week 03 task files |

## How to View Tasks

1. Clone the repository.
2. Checkout the `week-03/tasks` branch.
3. Open the `Day-01` and `Day-02` folders.
4. Review the task files.
