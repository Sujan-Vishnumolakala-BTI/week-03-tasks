## 📖 Overview

This task demonstrates how to work with different JavaScript data types and perform arithmetic operations after converting them into numbers. It also shows how to format the final result for better readability.

---

## 🎯 Objectives

- 🔢 Use integer and floating-point numbers
- 🔤 Convert numeric strings into numbers
- ✅ Convert a boolean value into a numeric value
- ➕ Perform arithmetic operations
- 🎯 Display the output with two decimal places

---

## 📚 Concepts Covered

- Variables (`let`)
- Number Data Type
- String Data Type
- Boolean Data Type
- Type Conversion
- Ternary Operator
- Arithmetic Operators
- Number Formatting
- Console Output

---

## ⚙️ How It Works

1. Two numeric values are created.
2. Two numeric values stored as strings are converted into numbers.
3. A boolean value is converted into either **1** or **0**.
4. All values are added together.
5. The final result is formatted to display **two decimal places**.

---

## 📊 Expected Output

**Sum = 89.36**

---

After completing this task, you will be able to:

- Convert strings into numeric values.
- Convert boolean values for mathematical operations.
- Perform calculations using different data types.
- Format decimal numbers for clean output.
