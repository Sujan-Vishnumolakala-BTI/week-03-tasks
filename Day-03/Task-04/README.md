# 🔢 Array Frequency Counter Using JavaScript Map

<p align="center">
  <b>A simple JavaScript project to count the occurrence of each element in an array using the powerful Map data structure.</b>
</p>

---

## 📌 Project Overview

This project demonstrates how to analyze an array and find how many times each value appears.

Using JavaScript's built-in **Map**, each unique element is stored as a key, and its frequency is maintained as the corresponding value.

This is a common programming pattern used in:

- 📊 Data analysis
- 🔍 Duplicate detection
- 📈 Frequency calculations
- 🧮 Counting problems
- ⚡ Efficient data processing

---

## 🎯 Objective

Given an array containing repeated values, the objective is to:

- ✅ Identify unique elements
- ✅ Count the occurrence of each element
- ✅ Store the results using a JavaScript Map
- ✅ Display the frequency of every value

---

| Technology | Purpose |
|------------|---------|
| JavaScript | Programming language |
| Map | Store key-value frequency pairs |

---

## 🧠 How It Works

The application follows a simple frequency-counting approach:

1. 📥 Take an input array containing multiple values.
2. 🗂️ Create a Map to store each value and its count.
3. 🔄 Traverse through every element in the array.
4. 🔎 Check whether the value already exists in the Map.
5. ➕ Increase the count if it exists.
6. 🆕 Add a new entry if it appears for the first time.
7. 📋 Display the final frequency table.

## 🚀 Why Use JavaScript Map?

`Map` is an ideal choice for frequency counting because it provides:

- ✨ Fast key lookup
- ✨ Easy value updates
- ✨ Clear key-value structure
- ✨ Maintains insertion order
- ✨ Better readability for frequency problems
